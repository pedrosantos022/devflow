# Papel:  Infraestrutura

A área de Infraestrutura foi escolhida por ser responsável por preparar e manter o ambiente necessário para o funcionamento do projeto. Uma infraestrutura bem organizada é fundamental para garantir que os sistemas, aplicações e serviços tenham um ambiente adequado para serem executados.

Além disso, a documentação da infraestrutura facilita a manutenção do projeto e permite que outras pessoas da equipe possam compreender as configurações realizadas e dar continuidade ao trabalho.

# Responsabilidades da área

A área de Infraestrutura possui as seguintes responsabilidades:

- Preparar e configurar o ambiente necessário para o projeto.
- Organizar os recursos utilizados pela aplicação.
- Configurar servidores, sistemas e serviços necessários.
- Garantir o funcionamento e a disponibilidade dos ambientes.
- Auxiliar na segurança e no controle de acesso aos recursos.
- Realizar manutenções e atualizações quando necessário.
- Identificar e solucionar problemas relacionados à infraestrutura.
- Documentar configurações, procedimentos e informações importantes.
- Garantir que a infraestrutura esteja preparada para as necessidades do projeto.

# Habilidades necessárias

Para atuar na área de Infraestrutura, é necessário possuir conhecimentos técnicos e capacidade de organização.

# Conhecimentos técnicos

- Sistemas operacionais.
- Redes de computadores.
- Servidores e serviços.
- Segurança da informação.
- Configuração de ambientes.
- Git e GitHub.
- Conceitos de backup e recuperação.
- Monitoramento e manutenção de sistemas.

# Habilidades pessoais

- Organização.
- Responsabilidade.
- Atenção aos detalhes.
- Capacidade de resolver problemas.
- Trabalho em equipe.
- Comunicação.
- Capacidade de documentar processos de forma clara.

# Entregas previstas

As principais entregas da área de Infraestrutura são:

- Ambiente preparado para o funcionamento do projeto.
- Configurações de infraestrutura organizadas.
- Documentação dos procedimentos realizados.
- Documentação das ferramentas e recursos utilizados.
- Organização dos arquivos relacionados à infraestrutura.
- Orientações para manutenção e utilização do ambiente.
- Registro das configurações importantes para facilitar futuras alterações.

A infraestrutura do projeto foi preparada e documentada com o objetivo de facilitar a utilização, manutenção e continuidade do sistema.

# Com quem a área de Infraestrutura trabalharia

A área de Infraestrutura trabalha em conjunto com as demais áreas envolvidas no projeto.

# Desenvolvimento

A equipe de Infraestrutura fornece o ambiente necessário para que os desenvolvedores possam executar, testar e disponibilizar a aplicação.

# Banco de Dados

Pode trabalhar em conjunto com a equipe responsável pelo banco de dados para garantir que o ambiente tenha os recursos e configurações necessários para o armazenamento e acesso às informações.

# Segurança

A infraestrutura também possui relação com a área de Segurança, principalmente em questões relacionadas a acessos, permissões, proteção dos sistemas e dados.

# Gestão do projeto

A área mantém comunicação com a gestão para entender as necessidades do projeto e garantir que os recursos de infraestrutura estejam de acordo com os objetivos definidos.

# Impacto caso a área não existisse

A ausência de uma área responsável pela Infraestrutura poderia causar diversos problemas no projeto.
Sem essa função, poderiam ocorrer:

- Problemas na configuração dos ambientes.
- Dificuldades para executar e testar a aplicação.
- Indisponibilidade de serviços.
- Maior dificuldade para identificar e solucionar problemas.
- Falta de organização dos recursos tecnológicos.
- Riscos relacionados à segurança e ao controle de acesso.
- Dificuldade para realizar manutenção.
- Dependência de uma única pessoa para entender as configurações.
- Perda de conhecimento devido à falta de documentação.

Por isso, a Infraestrutura é importante para garantir que o projeto tenha uma base tecnológica organizada, funcional e documentada.

# Resultado esperado

Com a atuação da área de Infraestrutura, espera-se que o projeto possua um ambiente preparado para seu funcionamento, com configurações organizadas e procedimentos devidamente documentados.
A documentação também permite que novos integrantes da equipe consigam entender a estrutura utilizada e realizar manutenções ou alterações sem depender exclusivamente da pessoa que realizou a configuração inicialmente.

# Conclusão

A área de Infraestrutura possui um papel fundamental no projeto, pois fornece a base necessária para que as outras áreas possam desenvolver e utilizar o sistema.
Além da preparação dos ambientes e recursos, a documentação realizada contribui para a organização, segurança e continuidade do projeto, facilitando futuras manutenções e evitando a perda de informações importantes.
